# PI-II-Time-8-

## Sobre o projeto

Sistema de acompanhamento de demandas de desenvolvimento (tarefas, defeitos, melhorias
e documentação), desenvolvido para o componente curricular Projeto Integrador II, com
base no Documento de Visão fornecido pelos professores orientadores.

## Estrutura do projeto

```
frontend/    → telas do sistema em HTML, CSS e script em JavaScript
backend/     → API do sistema e backend em geral (fase futura, ainda não iniciada)
database/    → scripts do banco de dados (fase futura, ainda não iniciada)
docs/        → documentação do grupo
```

## Documentação

* [docs/estrutura.md](docs/estrutura.md) — como usar a estrutura de pastas e o fluxo de trabalho no Git
* [docs/design.md](docs/design.md) — padrão visual e regras de design do sistema
* [docs/convencao-commits.md](docs/convencao-commits.md) — como escrever as mensagens de commit

## Como visualizar as telas

Abra qualquer arquivo `.html` dentro de `frontend/pages/` diretamente no navegador
(ou com a extensão Live Server do VS Code). Não é necessário instalar nada nesta etapa
do projeto.
